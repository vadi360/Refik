01

Proje Özeti

Refik, Türkiye'deki avukatlara yönelik, mobil öncelikli yapay zeka destekli bir hukuk asistanı ve tevkil pazar yeridir.

⚖️

Tevkil Pazar Yeri

Avukatlar arası otomatik eşleştirme ile duruşma ve işlem takibi. Konum, uzmanlık ve puan bazlı algoritma ile en uygun avukatı bulun.

📋

UETS Entegrasyonu

PTT UETS'ten tebligat çekme ve AI ile analiz. 5 gün kuralı otomatik takibi ve süre çıkarımı.

🤖

UYAP Özetleme

Tarayıcı eklentisi ile UYAP'tan dosya çekme ve RAG tabanlı akıllı özetleme. Aleyhe/lehe karar tespiti.

📝

Otomatik Belge Üretimi

AI ile dilekçe, ihtarname ve içtihat araştırması. Revize döngüsü ile istediğiniz formata getirme.

📱

Mobil Öncelikli Tasarım

Web, mobil ve Chrome eklentisi ile her platformdan erişim. Türkiye'nin ilk mobil öncelikli hukuk asistanı.

🔔

Çoklu Bildirim Sistemi

Push, SMS, E-posta, WhatsApp ve Telegram ile 5 kanalda bildirim. Asla önemli bir tebligatı kaçırmayın.

02

Teknoloji Stack

Modern ve güvenilir teknolojiler ile inşa edilmiş, ölçeklenebilir bir mimari.

Backend

  • NestJS 10 — Ana Framework
  • TypeScript 5.3 — Tip Güvenliği
  • Node.js 18+ — Runtime
  • Prisma — Veritabanı ORM
  • PostgreSQL — Ana Veritabanı
  • Redis — Önbellek

Frontend

  • Next.js — Web Uygulaması (PWA)
  • React 18 — Kullanıcı Arayüzü
  • React Native — Mobil Uygulama
  • Tailwind CSS — Stil
  • Zustand — Durum Yönetimi
  • Expo — Mobil Geliştirme

Yapay Zeka

  • Minimax M2.7 — Varsayılan AI (Türkiye)
  • Claude Sonnet 4 — Kritik Görevler
  • Pinecone — Vektör Veritabanı (RAG)
  • CloudFlare R2 — Dosya Depolama
  • Hibrit AI Mimarisi — Admin Kontrolü
  • RAG Anti-Halüsinasyon — Kaynak Gösterme

Altyapı

  • Docker — Konteynerizasyon
  • AWS — Bulut Altyapısı
  • Nginx — Web Sunucusu
  • Cloudflare — CDN ve Güvenlik
  • JWT + OTP — Kimlik Doğrulama
  • TLS 1.3 — Şifreleme
